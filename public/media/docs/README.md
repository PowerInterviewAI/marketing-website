# Docs media

Screenshots and diagrams referenced from the markdown in `src/content/docs/`.
Unlike `../marketing/`, this folder is **mixed** — most files are real captures,
a few are placeholders waiting on a screenshot.

Markdown can't carry `width`/`height`, so `src/lib/media.ts` reads each file's
intrinsic size off disk at render time and stamps it onto the element. Nothing
here needs a fixed size, and swapping a file for one of different dimensions is
safe — the reserved box follows the file.

## Demo clips

The long demo videos are **not** duplicated here. Docs markdown references the
shared clips in `public/media/` directly (`live-interview-assistant.mp4`,
`coding-challenge-1.mp4`). Each renders with a poster from
`public/media/marketing/`, wired up in `src/lib/media.ts` — add an entry there
if you embed another clip, or it will paint a black rectangle until played.

## Alt text

Alt text doubles as the visible caption under each figure
(`src/components/docs/MarkdownImage.tsx`), so write a real description. Filler
like `![Image](…)` is recognised and suppressed from the caption, but it still
leaves a screen reader with nothing — don't add more of it.
